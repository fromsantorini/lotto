# 시간순 백테스트 별도 추천 설계

## 목표

기존 LSTM 추천 2세트와 통계 가중 추천 3세트를 변경하지 않고, 과거 시간순
백테스트에서 추천 1세트당 평균 일치 번호 수가 가장 높았던 방식으로 별도 추천
5세트를 생성한다.

로또는 독립시행이므로 백테스트 성적이 미래 당첨 확률 상승을 보장하지 않는다.
신규 추천은 과거 기록에 대한 비교 실험 결과이며 이 한계를 화면에 함께 표시한다.

## 범위

- `tools/train-lstm-lotto.py`에 별도 백테스트 및 추천 생성 추가
- `lstm-prediction.json`에 백테스트 요약과 추천 5세트 추가
- `index.html`에 기존 추천과 분리된 백테스트 추천 영역 추가
- 기존 예측 이력 및 성적표 흐름으로 신규 추천 자동 채점

기존 LSTM 학습, LSTM 추천 2세트, 통계 가중 추천 3세트와 해당 화면은 유지한다.

## 비교 방식

백테스트는 다음 데이터 기반 방식들을 비교한다.

- 균등 무작위 기준선
- 전체 누적 출현 빈도
- 최근 `10`, `25`, `50`, `100`, `200`회 출현 빈도
- 반감기 `10`, `25`, `50`, `100`, `200`회의 시간감쇠 빈도

빈도 방식은 모든 번호에 기본값 1을 더해 과거에 나오지 않은 번호도 선택 확률을
갖게 한다. 시간감쇠 방식에서 `age`회 전 번호의 가중치는
`2 ** (-age / half_life)`로 계산한다.

홀짝, 합계, 연번, 끝수, 번호 구간, 강세수, 소외수, 이월수는 백테스트
추천의 후보 탈락이나 가중치에 사용하지 않는다.

## 시간순 백테스트

모든 방식을 같은 구간에서 비교하기 위해 최초 200회 이후 회차만 평가한다. 각 평가
대상 회차에서 해당 회차보다 이전 기록만 사용한다. 각 비교 방식은 고정
시드로 추천 5세트를 생성하고, 실제 당첨번호와 일치한 번호 수의 5세트 평균을
기록한다. 미래 회차 정보는 방법 선택, 가중치 계산, 번호 생성에 사용하지 않는다.

전체 평가 회차에서 `일치 번호 수 합계 / 추천 세트 수`가 가장 높은 방식을 현재
회차 추천기로 선택한다. 최고 방식이 같은 조건에서 측정한 균등 무작위 성적과
이론 기준 `0.8`을 모두 넘지 못하면 균등 무작위를 선택한다.

평균 적중 수가 정확히 같으면 위 비교 방식의 선언 순서가 빠른 방식을 선택해 결과를
결정적으로 유지한다.

동일 입력에서는 동일한 비교와 추천이 나오도록 회차와 방식에 기반한 고정 시드를
사용한다.

## 신규 추천 생성

선택된 방식의 번호별 가중치로 1~45에서 6개를 비복원 추출해 5세트를 만든다.
다음 조건만 강제한다.

- 각 세트는 1~45 범위의 중복 없는 6개 번호다.
- 신규 추천 5세트는 서로 완전히 동일하지 않다.
- 역대 1등 당첨번호 6개와 완전히 동일한 조합은 제외한다.

역대 당첨번호와 일부가 겹치는 조합, 극단적인 홀짝·합계·연번 형태는 허용한다.

## 출력과 화면

`lstm-prediction.json`의 스키마 버전과 기존 필드는 유지한다. 기존
`recommendations` 배열 끝에 `walk-forward-backtest` 방식의 추천 5세트를
추가한다. 최상위 `backtest` 객체에는 다음 요약만 기록한다.

- 평가 지표: `mean-matches-per-set`
- 평가 회차 수
- 선택 방식
- 선택된 기간 또는 시간감쇠 설정
- 선택 방식의 평균 적중 수
- 균등 무작위의 평균 적중 수

화면에는 기존 추천 아래에 별도의 `백테스트 추천` 영역을 표시한다. 추천 5세트와
선택 방식, 평가 회차 수, 평균 적중 수, 무작위 기준 및 미래 성과를 보장하지 않는다는
경고를 보여준다.

기존 예측 이력은 `recommendations` 배열 전체를 보존하고 채점하므로 저장 구조를
추가하지 않는다. 신규 방식 이름만 기존 성적표 표시 이름에 연결한다.

## 오류 처리

백테스트에 필요한 기록이 부족하면 전체 학습 작업을 실패시키지 않고 균등 무작위
5세트를 생성한다. 유효한 5세트를 만들 수 없으면 잘못된 결과를 게시하지 않고 작업을
실패시킨다.

## 검증

기존 `--selftest` 자체 점검에 다음 검사를 추가한다.

- 평가 대상보다 이후 회차를 제거해도 해당 회차의 예측이 변하지 않는다.
- 역대 1등과 완전히 동일한 조합이 생성되지 않는다.
- 추천 5세트가 유효하고 서로 완전히 다르다.
- 동일 입력과 시드에서 백테스트와 추천 결과가 재현된다.
- 인위적으로 한 방식의 성적이 높도록 만든 자료에서 해당 방식을 선택한다.
- 성능 기준을 넘는 방식이 없으면 균등 무작위를 선택한다.

## 완료 기준

- 기존 추천 5세트의 생성과 표시가 그대로 유지된다.
- 별도 백테스트 추천 5세트가 생성되고 화면에서 분리되어 보인다.
- 추천 선택 근거와 무작위 기준을 확인할 수 있다.
- 기존 이력과 성적표에서 신규 추천이 실제 당첨번호와 대조된다.
- 자체 점검이 통과한다.
