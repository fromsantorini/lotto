# 추천 성적표 완료 결과 표시 설계

## 목표

추천 성적표에서 아직 추첨되지 않은 이번 주 추천을 숨기고, 채점이 끝난 회차만 간결하게 표시한다. 각 회차 제목 옆에는 실제 당첨번호 6개와 보너스 번호를 바로 표시한다.

## 변경 범위

- `renderLstmScoreboard`가 `result.matches`가 있는 항목만 목록에 렌더링한다.
- 요약 통계와 회차 목록이 같은 채점 완료 항목 배열을 사용한다.
- 회차 제목 영역에 기존 `renderBalls(result.winningNumbers, result.bonus)`를 재사용한다.
- 카드 아래의 중복된 실제 당첨번호 영역은 제거한다.
- 채점 완료 이력이 없으면 빈 상태 안내를 표시한다.

## 제외 범위

- 추천 생성, 학습, 이력 저장 형식은 변경하지 않는다.
- 추천 번호 패널과 통계 계산 방식은 변경하지 않는다.
- 새 컴포넌트나 의존성은 추가하지 않는다.

## 검증

- 미추첨 항목이 성적표 HTML에 포함되지 않는다.
- 채점 완료 회차의 제목 영역에 실제 번호와 보너스 번호가 표시된다.
- 실제 당첨번호가 회차 카드 안에서 중복 표시되지 않는다.
- 기존 추천별 적중 수와 등수 표시는 유지된다.
