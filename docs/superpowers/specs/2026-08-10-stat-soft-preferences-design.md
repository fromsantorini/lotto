# 적중 강조색 및 통계 추천 연성 선호 설계

## 목표

적중 번호를 모든 번호 구간 색상에서 선명하게 표시하고, 통계 추천 3세트가 강세수·소외수·이월수·연번을 똑같이 강제하는 문제를 없앤다.

## 적중 강조색

- 주 당첨번호 적중은 기존 금색 대신 자홍색 `#ff2d95`를 사용한다.
- 공 배경과 테두리 사이의 흰색 간격은 유지해 빨간색 공에서도 구분되게 한다.
- 보너스 적중의 보라색 `#8250df`는 유지한다.
- 클래스와 렌더링 구조는 바꾸지 않고 `.ball.hit` CSS만 변경한다.

## 통계 후보 생성

통계 추천에만 적용하며 LSTM 후보 생성은 변경하지 않는다.

- 최근 100회 기준 강세 상위 12개와 소외 하위 12개 분류는 설명 배지를 위해 유지한다.
- 후보는 강세 2개·소외 2개·중간 2개를 조립하지 않고 1~45 전체에서 중복 없이 6개를 뽑는다.
- 다음 안전·형식 조건은 계속 강제한다.
  - 홀짝 2~4개
  - 1~22 저구간 2~4개
  - 합계 90~180
  - 같은 끝수 최대 2개
  - 3연번 이상 제외
  - 역대 1등 조합 및 현재 묶음의 중복 조합 제외
- 이월수 포함과 연번 포함 여부는 후보 탈락 조건에서 제거한다.

## 연성 선호 점수

기존 5회 창 평균회귀 편차를 주 점수로 유지하고 아래 선호 위반량을 작은 보조 점수로 더한다.

```text
최종 점수 = window_deviation + 0.05 × preference_penalty

preference_penalty =
  |강세수 개수 - 2| / 6
  + |소외수 개수 - 2| / 6
  + |이월수 개수 - 1| / 6
  + (연번 선호와 후보의 연번 여부가 다르면 1, 같으면 0)
```

점수가 낮은 후보를 선택한다. 이 값은 당첨확률이 아니라 기존 구성 성향을 약하게 유지하는 결정론적 정렬 기준이다. 후보가 선호 형태와 다르더라도 탈락시키지 않는다.

## 출력과 화면

- `lstm-prediction.json` 스키마와 `reason` 필드는 유지한다.
- 실제 선택된 강세수·소외수·이월수·연번만 기존 배지에 표시한다.
- 현재 게시된 추천은 수정하지 않고 다음 데이터 갱신·재학습 때 새 생성 규칙을 적용한다.

## 검증

- 적중 CSS가 자홍색 `#ff2d95`를 사용한다.
- 통계 후보 생성 필터에 이월수와 연번 강제 조건이 없다.
- 선호 점수는 목표 구성에 가까운 후보에 더 낮은 값을 준다.
- 통계 추천은 여전히 범위·중복·균형 조건과 재현성을 만족한다.
- 기존 성적표 렌더 검사와 학습 스크립트 자체 점검이 통과한다.
