# 적중 강조색 및 무강제 가중 추천 설계

## 목표

적중 번호를 모든 번호 구간 색상에서 선명하게 표시한다. LSTM 2세트와 통계 3세트 모두 유효한 전체 조합을 후보로 허용하고, 분석 결과는 후보 탈락 조건이 아니라 선택 가중치로만 사용한다.

## 적중 강조색

- 주 당첨번호 적중은 기존 금색 대신 자홍색 `#ff2d95`를 사용한다.
- 공 배경과 테두리 사이의 흰색 간격은 유지해 빨간색 공에서도 구분되게 한다.
- 보너스 적중의 보라색 `#8250df`는 유지한다.
- 클래스와 렌더링 구조는 바꾸지 않고 `.ball.hit` CSS만 변경한다.

## 유일한 강제 조건

추천 후보에는 다음 조건만 강제한다.

- 1~45 범위에서 중복 없는 6개 번호
- 같은 추천 묶음 안에서 완전히 동일한 조합 제외
- 역대 1등 당첨번호 6개와 완전히 동일한 조합 제외

역대 조합과 일부 번호가 겹치는 것은 허용한다. 과거 당첨 조합 제외는 사용자가 요청한 상품 규칙이며 당첨확률을 높인다는 의미가 아니다.

## 강제하지 않는 분석 항목

다음 항목은 후보를 탈락시키지 않는다.

- 홀짝 비율
- 1~22와 23~45의 저·고 비율
- 번호 합계
- 같은 끝수 개수
- 연번 개수
- 강세수·소외수 개수
- 이월수 포함 여부
- 구간 분포와 최근 창 평균회귀 편차

극단적인 모양의 조합도 유효 후보이며, 분석 점수가 낮더라도 선택 가능성을 0으로 만들지 않는다.

## 공통 후보 생성

- 1~45에서 중복 없이 6개를 균등 생성한다.
- 역대 1등 조합과 후보 풀 내부 중복만 제거한다.
- 홀짝·합계·구간·연번 등을 검사해 후보를 버리는 기존 `is_balanced` 필터는 LSTM 학습·추론과 통계 추천에서 제거한다.
- 고정 시드를 유지해 같은 데이터에서는 같은 결과가 생성되게 한다.

## LSTM 추천 2세트

- 모든 실제 회차를 양성 학습 예제로 사용하며 균형 조건을 만족한 회차만 고르는 필터를 제거한다.
- 음성 예제도 유효한 전체 조합에서 생성하며 해당 양성 조합과 완전히 같은 조합만 제외한다.
- 추론 후보는 공통 후보 생성 규칙을 따른다.
- LSTM 점수를 양수 선택 가중치로 정규화한다.
- 후보 2개를 가중 비복원 추출한다. 높은 점수의 후보가 더 잘 뽑히지만 낮은 점수 후보도 선택 가능하다.
- 두 추천의 완전 중복만 금지하고 번호 교집합 개수는 강제하지 않는다.

## 통계 추천 3세트

- 모든 후보에 기존 통계 특성을 계산한다.
- 과거 분포와 최근 창을 이용해 각 후보의 상대 점수를 만들고 항상 0보다 큰 선택 가중치로 변환한다.
- 후보 3개를 가중 비복원 추출한다.
- 강세수·소외수·이월수·연번 등은 가중치와 설명 배지에만 반영한다.
- 실제 선택된 특성만 기존 `reason` 필드에 기록한다.

## 용어와 출력

- 가중치는 실제 당첨확률이 아니라 모델·통계에 따른 `선택 가중치`다.
- 모든 유효 조합의 실제 당첨확률은 동일하다는 기존 경고를 유지한다.
- `lstm-prediction.json`의 최상위 스키마 버전과 성적표 이력 구조는 유지한다.
- 현재 게시된 추천은 수정하지 않고 다음 데이터 갱신·재학습 때 새 생성 규칙을 적용한다.

## 검증

- 적중 CSS가 자홍색 `#ff2d95`를 사용한다.
- 생성 후보는 1~45 범위의 중복 없는 6개이며 역대 1등 조합과 다르다.
- 홀짝·합계·연번·이월수 등이 후보 탈락 조건으로 사용되지 않는다.
- 가중치가 낮은 후보도 0이 아닌 선택 가능성을 갖는다.
- 같은 입력과 시드로 결과가 재현된다.
- 기존 성적표 렌더 검사와 학습 스크립트 자체 점검이 통과한다.
