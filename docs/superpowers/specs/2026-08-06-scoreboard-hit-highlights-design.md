# 추천 성적표 적중 번호 강조 설계

## 목표

채점 완료된 추천 카드에서 실제 당첨번호와 일치한 번호를 즉시 식별할 수 있게 한다.

## 표시 규칙

- 실제 당첨번호 6개와 일치한 추천 공에는 `hit` 클래스를 적용해 굵은 금색 테두리와 빛 효과를 표시한다.
- 보너스 번호와 일치한 추천 공에는 `bonus-hit` 클래스를 적용해 보라색 테두리와 빛 효과를 표시한다.
- 주 당첨번호 일치를 보너스 일치보다 우선한다.
- 일치하지 않은 공과 실제 당첨번호 행은 기존 색상을 유지한다.
- 기존 적중 개수, 보너스 일치, 등수 표시는 유지한다.

## 구현 범위

- 기존 `renderBalls`에 선택적 강조 인자를 추가해 다른 호출은 변경 없이 유지한다.
- 추천 성적표에서만 실제 결과를 강조 인자로 전달한다.
- 새 의존성이나 별도 컴포넌트는 추가하지 않는다.

## 검증

- 주 당첨번호와 겹친 추천 공에 `hit` 클래스가 포함된다.
- 보너스 번호만 겹친 추천 공에 `bonus-hit` 클래스가 포함된다.
- 겹치지 않은 추천 공에는 강조 클래스가 없다.
- 실제 당첨번호 행과 다른 화면의 공 렌더링은 기존 출력과 같다.
